Clears the terminal and positions the cursor at its top left.

Clear the terminal using the standard ANSI escape sequence.

The escape sequence clears the visible screen and moves the cursor to row one, column one before the menu is printed.

◆ ProcessUserChoice()

void grocery::ui::UIController::ProcessUserChoice ( )

Reads and dispatches choices until the user quits.

Process menu input until the user selects a quit command.

Numeric choices are one-based in the user interface and converted to zero-based menu indexes internally.

Input is parsed as a complete token so values such as "2abc" cannot accidentally be accepted as menu choice two.
