void grocery::ui::Dialog::FindItem ( )

Repeatedly prompts for an item name and displays its count.

Run the repeated item lookup dialog until the user enters q.

Entering q returns to the main menu.

Trailing whitespace is removed so an accidental space does not change an otherwise valid item lookup.
