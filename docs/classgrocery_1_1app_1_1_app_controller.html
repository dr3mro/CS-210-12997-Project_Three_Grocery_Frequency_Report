void grocery::app::AppController::Run ( )

Runs the complete grocery application.

Load, persist, and interact with grocery frequency data.

Loads the default input file, writes the frequency report, creates the interactive menu, and processes user selections.

This method keeps startup sequencing in one place: data must be loaded before the output report or interactive views can be produced.
