grocery::ui::Item::Item ( std::string text,
std::function< void()> action )
explicit

Creates a menu item.

Store the text and callback for one menu entry.

Parameters
textText displayed for the item.
actionFunction executed when the item is selected.

An empty callback is permitted by the type system, but invoking an empty callback later may throw std::bad_function_call.

The constructor receives both values by value so callers may provide either lvalues or temporaries. Moving them into the object avoids an unnecessary second allocation or copy.
